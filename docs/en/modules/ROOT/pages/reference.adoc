== JUnit extension (`vauban-junit`)

`@VaubanTest` boots a lightweight container for tests:

[source,java]
----
@VaubanTest
class GreetingServiceTest {
    @Inject GreetingService greeting;

    @Test void hello() {
        assertEquals("Hello, Vauban!", greeting.hello("Vauban"));
    }
}
----
