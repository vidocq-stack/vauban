== Tests intentionally skipped

[cols="3,5"]
|===
| Category | Reason

| Runtime portable extensions (`Extension`, `BeforeBeanDiscovery`, `AfterBeanDiscovery`)
| Out of the Lite profile. Vauban implements only Build Compatible Extensions.

| `@ConversationScoped`
| Out of the Lite profile.

| `PassivationCapable` / passivation
| Out of the Lite profile. Beans are not serialisable.

| EL wired into managed beans
| Out of the Lite profile. `jakarta.el` is required only as a spec dependency, not activated on application beans.

| `@Specializes`
| Out of the Lite profile (deferred to a possible Full profile).
|===

* Arquillian tests requiring a servlet container: out of scope for Vauban (covered by xref:foy::tck.adoc[Foy]).
* Advanced EL tests: require an application-level EL evaluator, not wired in the Vauban runner.

== Reproduce locally

[source,bash]
----
cd vauban
sdk env
./mvnw -ntp -pl vauban-tck-runner test
----

The runner uses Arquillian + TestNG. The Surefire report lands in `vauban-tck-runner/target/surefire-reports/`.

[NOTE]
====
Per the workspace constraint, `vauban-tck-runner` is included in the Vauban reactor — unlike `cassini-tck` or `foy-tck`, which are detached because of ShrinkWrap Maven Resolver. The CDI TCK does not depend on ShrinkWrap Resolver in this configuration.
====
