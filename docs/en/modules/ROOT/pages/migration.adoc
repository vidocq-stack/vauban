== From Weld

Key differences:

* **No runtime AnnotatedType lookup** — Vauban resolves everything at compile time.
* **No `BeforeBeanDiscovery` / `AfterBeanDiscovery`** — replaced by Vidocq runtime `@BuildStep`s.
* **No runtime portable extensions** — use the Vidocq extension mechanism for the static parts, keep Weld portable extensions via a `[TODO]` adapter layer.
