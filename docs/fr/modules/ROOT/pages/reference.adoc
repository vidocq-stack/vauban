== Extension JUnit (`vauban-junit`)

`@VaubanTest` boote un container léger pour les tests :

[source,java]
----
@VaubanTest
class GreetingServiceTest {
    @Inject GreetingService greeting;

    @Test void hello() {
        assertEquals("Hello, Vauban!", greeting.hello("Vauban"));
    }
}
----
