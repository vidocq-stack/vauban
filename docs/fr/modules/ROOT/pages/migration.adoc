== Depuis Weld

Différences clés :

* **Pas d'AnnotatedType lookup runtime** — Vauban résout tout à la compilation.
* **Pas de `BeforeBeanDiscovery` / `AfterBeanDiscovery`** — remplacé par les `@BuildStep` du runtime Vidocq.
* **Pas de portable extensions runtime** — utiliser le mécanisme d'extensions de Vidocq pour ce qui est statique, conserver les portable extensions Weld via une couche d'adaptation `[TODO]`.
